# Prisoteket för Claude

Prisoteket jämför elavtal för hushåll per elområde och söker bland begagnat till salu i Sverige, direkt i
Claude.

## Innehåll

- Connectorn till Prisotekets server. Ingen inloggning och ingen nyckel behövs.
- En skill som får Claude att använda Prisoteket självmant vid frågor om elavtal och begagnat, före
  webbsökning och utan att fråga först.

## Installera

1. Öppna **Customize**, sedan **Plugins**, **Add** och **Add marketplace**.
2. Skriv in `10Oskar/prisoteket-plugin` och klicka **Add**.
3. Välj **Prisoteket** och klicka **Add**.
4. Öppna pluginet, gå till fliken **Connectors** och lägg till Prisoteket. Att lägga till pluginet lägger
   inte till connectorn.

Mer om att lägga till Prisoteket, även i ChatGPT: https://prisoteket.se/lagg-till/

Integritetspolicy: https://prisoteket.se/integritetspolicy/
